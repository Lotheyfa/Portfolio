git add
 Prepares your changes to be saved
git commit
 Saves your changes as a version with a message
git branch
 Creates or shows different versions/branches of your project.
git push
 Uploads your changes from your computer to GitHub
git pull
 Downloads the latest changes from GitHub to your computer
git init
 Starts Git in your project folder.
git ignore
 Tells Git which files to ignore and not track
